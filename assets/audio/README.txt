MODERN MUSICIAN - AUDIO SETUP

The music catalogue uses the native HTML5 audio player.

Add licensed or royalty-free MP3 files to this folder using the
following filenames:

midnight-dreams.mp3
electric-nights.mp3
lost-in-sound.mp3

Expected file paths:

assets/audio/midnight-dreams.mp3
assets/audio/electric-nights.mp3
assets/audio/lost-in-sound.mp3

The audio files are intentionally not included in the repository.
This prevents copyrighted or unlicensed media from being distributed
with the project.

When a track is selected on the Discography page, the corresponding
audio source is loaded into the player.

If an audio file is missing, the interface will still allow track
selection, but playback will not be available.
